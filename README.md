Entry for the [Have You Tried Turning It Off?](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b) competition on make.fun — one funny line a hopeless tech support agent says to a desperate customer, judged head-to-head by an AI comedy editor.

## The line

> Good news — your case is now with Tier 2, which is me again, but I've had a coffee and a little cry.

The joke: the agent "escalates" the case to Tier 2, which turns out to be the same agent — cheerfully useless, slightly more caffeinated, slightly more broken. The customer is never the butt of it.

## How to run

```sh
python3 main.py
```

This validates the line (single line, 1–199 UTF-8 characters, not only whitespace) and writes it to `/output/entry.txt`.
